# Jubelio App Store Developers

Build apps that work with Jubelio merchant data: products, stock, warehouses and finance.
A merchant installs your app from the Jubelio App Store, and your app calls the Jubelio Open API
on their behalf.

## How it works

1. **Create an app** in the Dev Console.
2. **A merchant installs it** from the App Store and approves the permissions it asks for.
3. **Your backend gets tokens** for that merchant.
4. **Your backend calls the Open API** with those tokens.
