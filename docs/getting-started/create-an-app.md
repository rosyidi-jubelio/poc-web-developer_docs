# Create an app

1. Sign in to the Jubelio Dev Console and create a new app.
2. Copy your **Client ID** and **Client secret**. Keep the client secret on your server only.
3. Choose the **scopes** (permissions) your app needs.
4. Set your **redirect URI**: the URL on your backend that receives the authorization code when a
   merchant installs your app.
5. Submit the app for review. Once it is live, merchants can install it from the App Store.

Then follow [Your first API call](./first-api-call.md).
